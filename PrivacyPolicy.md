Privacy Policy – Summarizer Chrome Extension

Last updated: 06 Feb 2026

The Summarizer Chrome Extension respects your privacy and is designed to collect the minimum data required to function.

Information We Collect
The extension temporarily accesses website content (text) from the active tab only after the user explicitly clicks the summarize button. This data is used solely to generate a summary.

How We Use Data
To generate summaries of the current webpage
To improve user experience within the extension

Data Storage
Webpage content is not stored permanently
No personal data is saved, logged, or shared
User preferences (such as summary length or style) may be stored locally using Chrome storage

Data Sharing
We do not sell, rent, or share user data with third parties, except when required to process the summary via a summarization service.

Security
All data processing occurs securely and only for the duration necessary to generate the summary.

User Control
The extension runs only on user action and only on the active tab.
